  <name>Task 1: Extend useBarcodeScanner with categorized error types</name>
  <files>app/hooks/useBarcodeScanner.ts</files>
  <action>
1. Add a new exported type: `export type ScanErrorType = 'permission-denied' | 'camera-not-found' | 'decode-failure' | null`

2. Add state: `const [scanErrorType, setScanErrorType] = useState<ScanErrorType>(null)`

3. Add an `onError` callback to the `useZxing` call:
   ```
   onError(error) {
       if (error.name === 'NotAllowedError') {
           setScanErrorType('permission-denied')
           setScanStatus('error')
           setIsScanning(false)
       } else if (error.name === 'NotFoundError') {
           setScanErrorType('camera-not-found')
           setScanStatus('error')
           setIsScanning(false)
       }
       // Other errors (decode errors during live scan) are normal — don't change state
   }
   ```

4. IMPORTANT CAVEAT (from research): `onError` may NOT fire for NotAllowedError/NotFoundError because these happen before decoder init. Add a proactive permission check. Create a wrapper around `setIsScanning(true)`:
   ```
   const startScanning = async () => {
       // Proactively check camera permission before starting
       try {
           const permission = await navigator.permissions.query({ name: 'camera' as PermissionName })
           if (permission.state === 'denied') {
               setScanErrorType('permission-denied')
               setScanStatus('error')
               return
           }
       } catch {
           // permissions.query not supported — fall through to useZxing
       }
       setScanErrorType(null)
       setScanStatus('idle')
       setIsScanning(true)
   }
   ```

5. For `handleImageUpload`, when the catch fires (no barcode found), set `setScanErrorType('decode-failure')` in addition to the existing `setScanStatus('error')`.

6. Add a `clearScanError` function: `() => { setScanErrorType(null); setScanStatus('idle') }`

7. Update the return object to include: `scanErrorType`, `startScanning`, `clearScanError` (keep `setIsScanning` for backward compat but forms should prefer `startScanning`).

8. Update the `UseBarcodeScanner` interface to include `scanErrorType: ScanErrorType`, `startScanning: () => Promise<void>`, `clearScanError: () => void`.
