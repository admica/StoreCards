  <action>
**For app/login/page.tsx:**

1. Add imports: `import { loginSchema, validateField } from '@/app/lib/validation'` and add `useState` to the react import.

2. Convert inputs to controlled: Login page currently has uncontrolled inputs (no value/onChange). Add state:
   ```
   const [email, setEmail] = useState('')
   const [password, setPassword] = useState('')
   const [fieldErrors, setFieldErrors] = useState<Record<string, string>>({})
   ```

3. Add `onBlur` and `onChange` to email input:
   ```
   value={email}
   onChange={(e) => {
       setEmail(e.target.value)
       if (fieldErrors.email) {
           const error = validateField(loginSchema, 'email', e.target.value)
           if (!error) setFieldErrors(prev => { const next = {...prev}; delete next.email; return next })
       }
   }}
   onBlur={(e) => {
       const error = validateField(loginSchema, 'email', e.target.value)
       if (error) setFieldErrors(prev => ({ ...prev, email: error }))
       else setFieldErrors(prev => { const next = {...prev}; delete next.email; return next })
   }}
   ```

4. Add same pattern to password input (using `password` state, `loginSchema`, `'password'` field name).

5. Toggle input border class based on error state. For each input, replace the static `border-border dark:border-border ... focus:border-accent focus:ring-accent/20` with a conditional:
   ```
   ${fieldErrors.email
       ? 'border-error focus:border-error focus:ring-error/20'
       : 'border-border dark:border-border focus:border-accent focus:ring-accent/20'}
   ```

6. Add field-level error display below each input:
   ```
   {fieldErrors.email && (
       <p className="mt-1 text-xs text-error" role="alert">{fieldErrors.email}</p>
   )}
   ```

7. Import and use shared SubmitButton: Replace the local `LoginButton` function and its usage with:
   ```
   import { SubmitButton } from '@/app/components/SubmitButton'
   // In JSX:
   <SubmitButton label="Sign in" pendingLabel="Signing in..." />
   ```
   Delete the entire `function LoginButton()` at the bottom of the file. Remove `useFormStatus` import if no longer used.
